# Web Scraper and Data Analysis System

## Project Description
A Python-based web scraping application that extracts useful information from public websites, organizes the collected data and presents it for analysis.

## Features
- Extract website headings and paragraphs
- Collect quotes, authors and tags from a sample website
- Scrape multiple pages
- Display extracted information in a table
- Analyze extracted data
- Generate visualizations
- Download scraped data as CSV

## Technologies Used
- Python
- Requests
- BeautifulSoup
- Pandas
- Streamlit
- Matplotlib

## Installation

Install the required packages:

pip install -r requirements.txt

## Run the Application

streamlit run app.py
